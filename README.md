# Application de scan des présences

Page web utilisée par les délégués pour scanner les cartes QR des étudiants. Elle ne contient aucune donnée : les listes et les scans sont lus et écrits dans le dépôt privé `presence-donnees`, à l'aide du jeton saisi sur chaque téléphone.

Le guide de mise en place se trouve dans le fichier `README.md` du dépôt `presence-donnees`.

Lecture des QR codes : bibliothèque jsQR (licence Apache 2.0).
